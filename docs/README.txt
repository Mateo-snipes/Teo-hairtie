Teo-hairtoggle - Scrunchie Item Version

1. Put the Teo-hairtoggle folder in your resources folder.
2. Add/ensure these resources are started before it:
   ensure ox_lib
   ensure ox_inventory
   ensure Teo-hairtoggle
3. Open ox_inventory/data/items.lua and add the item from:
   install/ox_inventory_item.lua
4. Restart ox_inventory and Teo-hairtoggle, or restart the server.
5. Give yourself the item named: scrunchie

Using the scrunchie once hides/ties up the current hair.
Using the same scrunchie again restores the exact saved drawable/texture.
The item is NOT consumed.

The old /hairtie command has been removed.
